# EveryTV downloads

**Android / Fire TV app:** [EveryTV.apk](https://github.com/emayushp/notv-apk/raw/main/EveryTV.apk)

Fire TV Downloader URL:

    github.com/emayushp/notv-apk/raw/main/EveryTV.apk

**Laptop (Windows / Mac / Linux):** [EveryTV-web.zip](https://github.com/emayushp/notv-apk/raw/main/EveryTV-web.zip)
Nothing to install: unzip and double-click `Start EveryTV.bat` (Windows) or `Start EveryTV.command` (Mac). Details are in the README inside the zip.

**Roku:** [EveryTV-roku.zip](https://github.com/emayushp/notv-apk/raw/main/EveryTV-roku.zip)
Install through Roku developer mode: Home ×3, Up ×2, Right, Left, Right, Left, Right on the remote, then upload the zip at `http://<roku-ip>`.

**iPhone / iPad:** [EveryTV.ipa](https://github.com/emayushp/notv-apk/raw/main/EveryTV.ipa)
Install from a Windows PC or Mac with Sideloadly (or AltStore) using your Apple ID. With a free Apple ID it has to be re-signed every 7 days.
